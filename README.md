**`os-info-kotlin`** is a Kotlin Multiplatform library for detecting the operating system type, version, edition, codename, bitness, and processor architecture. It is a faithful 1:1 transliteration port of the Rust [`os_info`](https://github.com/stanislav-tkach/os_info) crate (`v3.14.0`).

---

## Features

- **Comprehensive OS Detection:** Identifies **58** distinct operating systems and Linux distributions (`OsType`), including macOS, iOS, Android, Windows, FreeBSD, OpenBSD, NetBSD, DragonFly BSD, Illumos, AIX, Redox, Cygwin, Emscripten, and over 40 Linux distributions.
- **Rich Version Representation:** Models OS versions via a strongly-typed sealed hierarchy (`Version`):
  - `Version.Semantic(major, minor, patch)` — e.g. `14.5.0`
  - `Version.Rolling(date)` — e.g. `Rolling Release` or `Rolling Release (2026.05.01)`
  - `Version.Custom(value)` — arbitrary version strings when non-semantic
  - `Version.Unknown` — safe sentinel when version information is unavailable
- **Bitness & Architecture Discovery:** Reports OS bitness (`Bitness.X32`, `Bitness.X64`, `Bitness.Unknown`) and hardware machine architecture (`x86_64`, `arm64`, `aarch64`, etc.), as well as optional OS `edition` and `codename`.
- **First-Class Serialization:** All public data types (`Info`, `OsType`, `Version`, `Bitness`) are annotated with `@Serializable` from `kotlinx.serialization` out of the box.
- **True Kotlin Multiplatform + Swift Export:** Targets JVM, Android, Android Native, macOS, iOS, watchOS, tvOS, Linux, Windows (`mingwX64`), JavaScript (Browser & Node.js), and WebAssembly (`wasmJs` & `wasmWasi`), with native **Swift Export** (`OsInfo` SPM package & XCFramework).
- **1:1 Upstream Fidelity:** Every source file and test suite tracks its upstream Rust counterpart in [`stanislav-tkach/os_info`](https://github.com/stanislav-tkach/os_info) with `port-lint` provenance headers and full test parity.

## Usage Examples

### 1. Basic OS Detection

```kotlin
import io.github.kotlinmania.osinfo.get

fun main() {
    val info = get()

    // Print formatted OS summary (e.g., "Mac OS 14.5.0 [64-bit]"):
    println("OS information: $info")

    // Access individual fields:
    println("Type:         ${info.osType}")
    println("Version:      ${info.version}")
    println("Edition:      ${info.edition}")
    println("Codename:     ${info.codename}")
    println("Bitness:      ${info.bitness}")
    println("Architecture: ${info.architecture}")
}
```

### 2. Pattern Matching on `OsType`, `Version`, and `Bitness`

```kotlin
import io.github.kotlinmania.osinfo.Bitness
import io.github.kotlinmania.osinfo.OsType
import io.github.kotlinmania.osinfo.Version
import io.github.kotlinmania.osinfo.get

fun describeEnvironment(): String {
    val info = get()

    val family = when (info.osType) {
        OsType.Macos, OsType.Ios -> "Apple Darwin"
        OsType.Windows, OsType.Cygwin -> "Windows"
        OsType.Android -> "Android"
        OsType.FreeBSD, OsType.OpenBSD, OsType.NetBSD, OsType.DragonFly,
        OsType.HardenedBSD, OsType.MidnightBSD -> "BSD"
        OsType.Unknown -> "Unknown"
        else -> "Linux / Unix (${info.osType})"
    }

    val versionDetail = when (val v = info.version) {
        is Version.Semantic -> "v${v.major}.${v.minor}.${v.patch}"
        is Version.Rolling -> v.date?.let { "rolling ($it)" } ?: "rolling"
        is Version.Custom -> v.value
        Version.Unknown -> "unknown version"
    }

    val pointerWidth = when (info.bitness) {
        Bitness.X64 -> "64-bit"
        Bitness.X32 -> "32-bit"
        Bitness.Unknown -> "unknown-bit"
    }

    return "$family — $versionDetail ($pointerWidth, arch=${info.architecture ?: "n/a"})"
}
```

### 3. Parsing and Comparing Versions

`Version` and `Info` both implement `Comparable`, and `Version.fromString` automatically parses `"major.minor.patch"` strings into `Version.Semantic` or falls back to `Version.Custom`:

```kotlin
import io.github.kotlinmania.osinfo.Version

fun checkMinimumVersion() {
    val parsed = Version.fromString("22.04.4")
    // parsed == Version.Semantic(22u, 4u, 4u)

    val minimum = Version.Semantic(20u, 4u, 0u)
    check(parsed >= minimum) { "Requires at least 20.04.0, found $parsed" }

    val custom = Version.fromString("2026-lts-preview")
    // custom == Version.Custom("2026-lts-preview")
}
```

### 4. Serialization with `kotlinx.serialization`

All core types (`Info`, `OsType`, `Version`, `Bitness`) are `@Serializable`:

```kotlin
import io.github.kotlinmania.osinfo.Info
import io.github.kotlinmania.osinfo.get
import kotlinx.serialization.encodeToString
import kotlinx.serialization.json.Json

fun serializeOsInfo(): String {
    val info: Info = get()
    val json = Json { prettyPrint = true }
    val encoded = json.encodeToString(info)
    val decoded = json.decodeFromString<Info>(encoded)
    check(info == decoded)
    return encoded
}
```

### 5. Swift Interop (via Kotlin Swift Export)

```swift
import OsInfo

let info: Info = get()
print("OS Type: \(info.osType)")
print("Bitness: \(info.bitness)")
```

## Core API Overview

| Symbol | Description |
| :--- | :--- |
| `fun get(): Info` | Detects and returns the current operating system's `Info`. |
| `data class Info` | Holds `osType: OsType`, `version: Version`, `edition: String?`, `codename: String?`, `bitness: Bitness`, and `architecture: String?`. |
| `enum class OsType` | Enumeration of all 58 recognized operating systems and distributions. |
| `sealed class Version` | `Version.Unknown`, `Version.Semantic(major, minor, patch)`, `Version.Rolling(date)`, or `Version.Custom(value)`. |
| `enum class Bitness` | `Bitness.Unknown`, `Bitness.X32` (`"32-bit"`), or `Bitness.X64` (`"64-bit"`). |
